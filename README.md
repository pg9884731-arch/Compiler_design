
  # Enterprise AI Dashboard

  This is a code bundle for Enterprise AI Dashboard. The original project is available at https://www.figma.com/design/Z85mVjzunL14vc8EoV1PO6/Enterprise-AI-Dashboard.

  ## Running the code

  Generated folders such as `node_modules` and `dist` are intentionally excluded from this repository. They are recreated locally and are not needed to preserve the UI.

  1. Install dependencies with `pnpm install` (or `npm install`).
  2. Start the development server with `pnpm dev` (or `npm run dev`).
  3. Open the local URL shown in the terminal.

  The source, styles, package manifest, and lockfile are retained so the same UI can be reproduced after cloning.
